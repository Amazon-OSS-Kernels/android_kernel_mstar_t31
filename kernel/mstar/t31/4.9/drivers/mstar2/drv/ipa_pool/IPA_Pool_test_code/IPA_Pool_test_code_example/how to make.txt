可见，
CMA0,CMA1,CMA2是无缝衔接的;CMA3,CMA4,CMA5也是无缝衔接的；
由于0x8800000 + 0x2000000 = A800000;
0x1FC00000 + 0x1400000 < 0x1FC00000
可以新设个如下的CMA6：
CMA6=heap00,miu=1,hid=28,sz=0x1400000,st=0xA800000

具体做法是在scripts/set_config文件里改成如下的：
setenv CMA6_Args CMA6=heap00,miu=1,hid=28,sz=0x1400000,st=0xA800000
