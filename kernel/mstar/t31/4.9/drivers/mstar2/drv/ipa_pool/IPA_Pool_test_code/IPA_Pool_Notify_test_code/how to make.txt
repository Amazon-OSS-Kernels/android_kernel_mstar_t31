在bootcmd arg里面新增了：
CMA5=DFB_TEMP,miu=0,hid=27,sz=0x1400000,st=0xFC00000
而进行测试的（注意st的值是根据原有的cat /proc/cmdline里的值的情况算出来的），所以./IPA_Pool_Notify_test_code.c里的目前test code是base这个heap测试的。
